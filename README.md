# 📖 Al-Furkan — الفُرقان

**Al-Furkan is A modern, full-featured open-source Quran app built with Flutter.**

> A full-featured, production-ready Islamic app — not just a demo.

Al-Furkan is a **production-ready Flutter Quran app (cross-platform ready)** built with **BLoC + Clean Architecture** and **Uthmanic (QCF) script rendering**—designed for daily reading, deep study, remembrance, and personalization.

It includes an interactive mushaf, tafsir and translation resources, a word-level Ayah library, prayer times, qibla, azkar, collections, notifications, and a fully customizable **“Ayah of the Day”** home widget.

_Whether you are a daily Quran reader, a student of knowledge, or a Flutter developer building a serious product… Al-Furkan is made to serve you._

## 🏆 Why Al-Furkan (ليه الفُرقان؟)

- **Production-ready Flutter Quran app** مش مجرد demo: مشروع معماري واضح، قابل للتوسعة، ومتجه للتشغيل الحقيقي.
- **Uthmanic script rendering (QCF Mushaf)** بتجربة قريبة جدًا من المصحف الورقي، مع دعم Dark/Light.
- **Ayah Library قوية (Word-level tools)**: اختيار كلمة من الآية وعرض (ترجمة/إعراب/صرف/قراءات) بدون زحمة.
- **Resource Management محترم**: تحميل/حذف موارد (تفاسير/ترجمات/كلمة بكلمة) مع متابعة الحجم والتقدم.
- **Daily Muslim utilities** داخل نفس التطبيق: Prayer Times, Qibla, Azkar, Khatma, Notifications.
- **Performance & Packaging mindset**: تحسينات حقيقية لتقليل حجم الباندل وتسريع الإقلاع.

## 🏗️ Architecture (BLoC + Clean Architecture)

التطبيق مبني كـ **open-source Quran application** حقيقي، مش مجرد واجهة—والهدف إن التطوير يفضل سهل ومضمون مع الوقت.

### ✅ مبادئ سريعة

- **Presentation**: UI + `Bloc/Cubit` + Widgets.
- **Domain**: Use-cases + Entities (منطق نظيف مستقل عن Flutter).
- **Data**: Repositories + DataSources (Local/Assets/Downloads) + Models.

### 🔧 Tech Stack (مختصر وقوي)

- **Flutter 3.x + Dart**
- **flutter_bloc / Cubit** (State Management)
- **qcf_quran_with_update** (Uthmanic/QCF rendering)
- **hive_ce** (Offline local storage)
- **just_audio** (Audio engine)
- **home_widget + workmanager** (Home widget updates)
- **awesome_notifications** (Notifications)
- **share_plus** (Sharing)
- **flutter_animate** (Subtle UI motion)

### 🧩 Deep Refactor (معلومة مهمة للمساهمين)

تم تفتيت شاشة المصحف العملاقة `mushaf_screen.dart` (التي تجاوزت 7600 سطر) إلى مكونات مستقلة:

1. **`widgets/`**: (الفهرس، الخيارات السفلية، الختمة، البحث، والتقييم) لتقليل الـCoupling.
2. **`extensions/`**: فصل وظائف النطق/المشاركة كصورة باستخدام `part`.
3. تحسينات لونية مركزية لدعم الوضع الداكن في النوافذ المنبثقة.

### ⚡ Performance & Packaging

تمت إضافة مسار واضح لتحسين الأداء وتقليل حجم الحزمة قبل التثبيت:

- **تقليل حجم الباندل قبل التثبيت** عبر استبدال إدراج مجلدات كاملة من الأصول بقائمة ملفات محددة فعليًا في التطبيق.
- **تحميل خطوط صفحات المصحف QCF عند الطلب** بدل تسجيل مئات عائلات الخطوط مسبقًا داخل الحزمة.
- **تسريع أول تشغيل** عبر تأجيل تهيئة الموارد الثقيلة وتجهيز بعض الخدمات إلى ما بعد ظهور أول واجهة للمستخدم.
- **تنظيف الحزمة النهائية** باستبعاد ملفات تطوير/عرض وموارد كبيرة غير مستخدمة من النسخة الموزعة للمستخدم.

## 🚀 Installation

لتشغيل تطبيق "الفُرقان" على جهازك أو المساهمة في تطويره:

### المتطلبات الأساسية (Prerequisites)

- [Flutter](https://docs.flutter.dev/get-started/install) (3.x أو أحدث)
- VS Code أو Android Studio

### الخطوات (Steps)

1. **Clone**

```bash
git clone https://github.com/IDRISIUMCorp/al-furkan-quran-flutter-app.git
```

1. **Install dependencies**

```bash
flutter pub get
```

1. **Run (Android)**

```bash
flutter run
```

> ملاحظة للمطورين: التطبيق يعتمد على قواعد بيانات محلية (`hive_ce`) ولا يتطلب أي إعدادات خوادم أو مفاتيح API خارجية للتشغيل المبدئي.
