# تطبيق الفرقان لحفظ القرآن الكريم — وضع الزن (Al-Furkan Zen Hifz)

تطبيق قرآني خاص موجه لحفظ القرآن الكريم وتثبيته بعيداً عن أي مشتتات أو قوائم معقدة، مبني بمعمارية Clean Flutter ومتوافق مع أحدث إصدارات أندرويد (SDK 35 / Min SDK 24).

---

## 🌟 الميزات الجوهرية (Specifications)

1. **واجهة الزن الخالية من المشتتات (Zen Hifz Mode):**
   - **الوضع النهاري:** خلفية ورق دافئ (`#FBF8F3`)، بطاقات ناعمة (`#F2ECE1`)، نص فحمي غامق (`#1E201D`)، ولمسات خضراء هادئة (Sage Green `#4A6B5D`).
   - **الوضع الليلي للحفظ:** خلفية حجرية داكنة (`#121615`)، نص قرآني بلون العنبر الدافئ (`#E6D5B8`) لحماية العين أثناء صلاة الفجر والتهجد.
   - **التركيز التلقائي:** إخفاء الشريط العلوي وشريط التنقل السفلي فور بدء التكرار أو التسميع الصوتي.
   - **حجب الآيات المتدرج (3 مستويات):**
     1. ظاهر بالكامل (Visible).
     2. مموه وضبابي (Blurred - `ImageFilter.blur`).
     3. مخفي بنقاط `•••••` (Hidden) مع ميزة التلصص المؤقت (Tap to Peek) لمدة 2.5 ثانية باللون الأخضر.

2. **محرك التكرار الصوتي (`AudioPlayerService` via `just_audio`):**
   - **قائمة تشغيل متصلة بدون فجوات (`ConcatenatingAudioSource`):** دمج مقاطع الآيات المحددة بسلاسة تامة.
   - **تتبع التكرار الفردي والجماعي (Loop Counting):** تكرار الآية الواحدة $N$ مرات ثم ربط مقطع الآيات كاملاً $M$ مرات مع وسوم `AyahPlaybackTag` للبث اللحظي للواجهة عبر `sessionStateStream`.
   - **فترة الصمت القابلة للتخصيص (Configurable Pause Delay):** توليد ملفات صوتية صامتة برمجياً في الذاكرة المؤقتة (`SilentWavGenerator`) كعناصر تشغيل حقيقية، لتطبيق مهلة الصمت ($X$ ثانية) للترديد والتسميع من الذاكرة دون انقطاع أو أخطاء.
   - **حماية الأداء:** استدعاء غير متزامن `unawaited(player.play())` لمنع أي تجميد لواجهة المستخدم أثناء التحميل المسبق.

3. **حلقة الأصدقاء الصوتية (Halaqa Room):**
   - غرف صوتية عبر WebRTC باستخدام LiveKit Client.
   - توليد الـ JWT Token محلياً داخل التطبيق (`ServerlessLiveKitToken`) بدون الحاجة لخادم وسيط.
   - وميض أخضر تفاعلي عند تحدث أي حافظ في الحلقة.

4. **جدول الصلاة والمنبهات المتصاعدة (Escalating Alarms):**
   - حساب مواقيت الصلاة حسب طريقة الجمهورية التونسية (زاوية الفجر 18°، زاوية العشاء 18°).
   - 4 مراحل متصاعدة لكل صلاة (معرفات 101 و 102 و 103 و 104) بفارق 5 دقائق.
   - شرط إلغاء الرنين: إنجاز ورد الحفظ المطلوب.

## 🚀 طريقة بناء حزمة أندرويد الخاصة (flutter build apk --release)

### 1. تثبيت الحزم وتنزيل نموذج الذكاء الاصطناعي للتسميع:
```bash
cd flutter_app
flutter pub get
dart run recite_quran:download_model
```

### 2. بناء ملف الـ APK:
```bash
flutter build apk --release
```

الملف الناتج سيكون جاهزاً للتثبيت المباشر على هاتفك وهواتف أصدقائك في المسار:
`flutter_app/build/app/outputs/flutter-apk/app-release.apk`
